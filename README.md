# Little Days · 小日子

一个用英文留住生活的个人日记网页应用。React + TypeScript + Vite，页面可继续由 GitHub Pages 托管；默认本地保存，可选使用腾讯云 CloudBase 同步，无需日记账号登录。

## 本地运行

需要 Node.js 22.12+（推荐 Node.js 24）。

```bash
npm install
npm run dev
```

打开终端显示的地址。开发服务默认允许局域网访问，手机可使用电脑的局域网 IP 和相同端口打开，但手机与电脑不会共享数据。

```bash
npm test
npm run build
npm run preview
```

`dist/` 可以部署到静态托管服务。建议使用 HTTPS；不要通过双击 `index.html` 的 `file://` 地址运行。

## 部署到 GitHub Pages

仓库已包含 GitHub Actions 工作流：推送到 `main` 分支后，会安装依赖、运行测试并构建，然后将 `dist/` 发布到 GitHub Pages。

1. 在 GitHub 仓库的 **Settings → Pages → Build and deployment** 中，将 **Source** 设为 **GitHub Actions**。
2. 将项目提交并推送到 `main`。在仓库的 **Actions** 页面查看 **Deploy to GitHub Pages** 的运行结果。
3. 部署成功后，从 **Settings → Pages** 打开网站。当前仓库的默认地址通常是 `https://xr-su.github.io/note-with-ai/`；实际地址以 GitHub 显示为准。也可以在 Actions 页面选择 `main` 分支手动运行工作流。

无需把 `dist/` 提交到 Git，也无需在仓库中保存 AI 密钥。日记和可选保存的密钥属于浏览器的当前网站来源；从本地开发地址切换到 Pages 后，原记录不会自动出现，请先导出 JSON 备份再导入。浏览器直连模型服务是否可用，仍取决于服务商的跨域策略和网络。

## 功能

- 当天日记：按浏览器本地日期每天一篇，多次打开继续记录。
- 日记记忆：在 AI 设置填写追溯天数（0–180，默认 0 关闭），聊天可参考此前已归档日记的标题和正文，不读取旧原始对话。
- 回忆：创建多篇独立经历，标题可编辑。
- 英文问题和中文辅助，一次一个追问。
- 保留中文或英文原文，下方显示英文翻译或纠正；英文纠错附简短中文说明。
- 原文与输入草稿自动保存在浏览器，刷新后可以从历史记录继续。
- 结束并归档时生成英文第一人称总结；保留完整对话，支持再次继续。
- 修改自己的回答后重新生成对应英文，并清除过时总结；后续对话保留。
- 历史记录搜索、模式筛选、整篇删除确认，以及 JSON 备份导出与导入。
- AI 失败、取消或超时后保留原文，支持手动重试，不自动重试付费请求。
- 温暖纸感界面，桌面侧栏、手机记录抽屉，无外部字体或图片 CDN 依赖。

## 配置 AI

打开右上角设置，输入你的 DeepSeek 或 MiniMax 国内平台 API 密钥，选择服务后保存。仅使用这两家国内 HTTPS API，**不调用 OpenAI**。

| 服务 | 国内端点 | 默认模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-flash` |
| MiniMax | `https://api.minimax.cn/v1/chat/completions` | `MiniMax-M3.1-Flash` |

DeepSeek 关闭思考，使用 JSON 模式；MiniMax 使用低思考档位，返回内容在本地校验。首次开场问题为固定双语问题，之后的追问、翻译、纠错及总结使用真实模型，不提供伪造的离线 AI 结果。

“日记记忆追溯天数”保存在当前浏览器，独立于密钥保存选项。以当前日记日期为基准，读取此前 N 个自然日内已归档的日记，排除当天、未归档日记和“拾起回忆”的记录。例如 11 月 23 日的日记设置 3 天，参考 11 月 20–22 日的归档；以后重开这篇日记仍使用该范围。从发送第一条回答后的聊天开始参考记忆，开场问题、单独纠错、最终归档和“拾起回忆”保持原有行为。修改设置后用于下一次请求，0 表示停止附带历史归档。开启后输入上下文会增长，实际费用也会增加。

价格、估算、选择理由及效果评估方法见 [模型对比](docs/model-comparison.md)，应用设置内也有简要对比。价格核查于 2026-11-13，以官方平台实际账单为准。没有真实密钥，因此**未做授权调用或实际效果排名**。

## 数据与安全

日记默认存储在当前网站来源的 `localStorage`，只有开启云同步后才会向 CloudBase 上传完整日记与草稿。AI 调用会把**当前篇**必要的对话发送给所选服务处理。默认不发送其他篇；开启日记记忆后，仅日记聊天额外发送追溯范围内已归档日记的日期、标题和正文，不发送旧原始对话、纠错解释或未发送草稿。历史作为往事背景，当前回答仍忠实纠正或翻译；单独纠错与最终归档只依据当前篇。不要输入不希望发送给模型服务的敏感信息。

密钥默认只留在当前页面内存，刷新后需要重新填写。勾选“记住”才会以明文存在浏览器，取消勾选会移除已保存密钥。浏览器同来源脚本可读取本地数据；请使用可信托管环境，不在共享设备上长期保存密钥。导出的备份仅包含日记，不包含密钥。

未开启云同步时，清除网站数据、换浏览器、换设备、换域名或端口会导致原来的记录不可见或被删除。请定期导出 JSON 备份。手动导入按记录 ID 合并；与已有记录 ID 相同或同一天的日记不会覆盖。损坏的存储或导入文件不会被静默覆盖；保存空间不足时，页面内容会保留在内存并显示备份提示。

## 可选的云端同步

设置 → 云端同步 → 创建同步空间。系统生成固定的随机口令，不允许自定义或修改；在其他设备选择“连接已有空间”，粘贴口令或扫描二维码。每台设备记住凭据，之后自动上传和下载。同步口令不包含在日记导出备份里；拥有口令的人可以读写日记，若所有保存口令的设备与自行保留的口令都丢失，没有邮箱找回功能。

打开应用、页面回到前台、网络恢复时检查云端；本地修改停止约 2 秒后上传。打开时先显示本地内容并暂时只读，约 3 秒后可选择继续离线编辑。上方云图标显示同步中、已同步、待上传、离线或失败，点击可查看状态与备份。关闭页面或浏览器休眠可能阻止最后一次上传，本地保存仍立即执行。

同步整份日记与草稿，**云端有新版本时会覆盖本地，不逐篇合并**；覆盖前保留最近 5 份本地备份，提供查看、导出和明确恢复。云端未变化时上传本地修改。上传检查云端版本，旧设备不能强行覆盖新云文件；网络错误、无效口令、格式损坏或本地保存失败时保留当前日记。AI API 密钥、日记记忆设置和同步口令不随日记上传，同步也不会自动调用 AI。

页面仍由 GitHub Pages 托管，CloudBase 只负责同步授权、版本检查与私有文件。快照文件在云函数内加密后存储，授权请求时云函数能解密；不承诺云服务运营者无法读取。云同步发送完整日记，与 AI 请求的记忆设置是不同的数据边界。

部署入口、接口约定和验证方式见 [后端部署](cloud/README.md)、[同步设计](docs/cloud-snapshot-sync.md) 与 [OpenAPI](docs/sync-api.openapi.yaml)。当前代码默认连接已部署的腾讯云上海测试接口，可通过 `VITE_SYNC_URL` 覆盖地址。默认网关域名仅用于测试；现有体验环境显示有效期至 2026-12-12，服务端测试 API Key 有效期至 2026-12-23。正式运行需另行确认域名与套餐。不要将腾讯云管理密钥配置成任何 `VITE_` 变量。

本地接口验证：`npm run dev:sync` 启动只监听本机、使用临时内存存储的真实同步处理器；运行 `postman collection run postman/collections/sync.postman_collection.json --no-report-events`。此模式不验证腾讯云 SDK、真实大陆访问或长期云端存储。

支持 Web Locks 的浏览器会限制同一网站只有一个标签页可写，其他标签页只读。没有 Web Locks 的环境请只在一个标签页记录；应用能检测存储变化，但不保证此类浏览器中的并发写入安全。Web Locks 通常需要 HTTPS 或 localhost。

由于是浏览器直接请求，模型平台必须允许来自当前网站的跨域访问。如果网络、账户或跨域策略禁止调用，页面会提示错误并保留原文；本应用不会绕过限制或使用未知代理。

## 验证范围

使用 Vitest 和 React Testing Library 验证本地数据、密钥策略、模型请求和 JSON 校验、HTTP 错误、超时、编辑恢复、归档重试草稿保护、继续对话、删除、多标签页只读保护，以及日记记忆的设置范围、自然日边界、模式隔离和旧原始对话不进入请求。所有模型响应测试均为合成响应，不证明真实模型质量或真实浏览器跨域可用性。

依照用户要求，不使用 Playwright 或 Superpowers 进行后续实现与验证。尚未在实际手机浏览器中验证最终弹窗布局；需使用自己的密钥确认网络和模型输出。
