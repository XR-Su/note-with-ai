# 日记场景模型对比

核查日期：2026-11-13。仅使用中国大陆服务，不接入 OpenAI。接口的兼容格式不意味着调用 OpenAI。

## 官方价格

单位：人民币 / 百万 tokens。价格可能调整，以链接中的最新定价为准。

| 模型 | 输入（无缓存） | 输入（缓存命中） | 输出 | 本应用设置 |
| --- | --- | --- | --- | --- |
| DeepSeek `deepseek-flash` | 空闲 ¥1 / 高峰 ¥2 | 空闲 ¥0.02 / 高峰 ¥0.04 | 空闲 ¥4 / 高峰 ¥8 | 关闭思考，JSON 模式 |
| MiniMax `MiniMax-M3.1-Flash` | ¥1 | ¥0.10 | ¥4 | `reasoning_effort: low`，思考无法关闭 |

DeepSeek 高峰：北京时间周一至周五（不含中国法定节假日）09:00–12:00、14:00–18:00，其他时间为空闲。不要只根据星期判断节假日费用。

假设每次 2,000 输入 tokens、300 输出 tokens，1,000 次回复：DeepSeek 空闲 ¥3.2、高峰 ¥6.4；MiniMax ¥3.2。这只是无缓存且不含额外思考 token 的算例，不是实际账单。MiniMax 的思考会额外占用输出及预算；多轮对话会反复发送本篇上下文，总输入会增长。归档和重新纠错也会产生单独调用费用。

## 功能效果与选择

默认 DeepSeek：此场景主要是短追问、中英翻译和基础纠错，不需要复杂推理。关闭思考并使用官方 JSON 输出功能更适合低成本交互和格式稳定性。MiniMax 是替代选择，可比较措辞风格，但 Flash 强制思考可能增加延迟和费用；低思考档位减少不必要推理。

这些是基于接口能力的工程判断，**不是实测质量排名**。官方能力说明与通用基准不足以证明某个模型在个人日记中更体贴、翻译更忠实或纠错更准确。本次没有用户 API 密钥，因此不声称已完成真实对话效果评测。

建议用同样的 5 组样本分别新建回忆测试（不要把不同模型回复混在同一次比较）：

1. `I go to park yesterday and I feel relax.`：过去时、冠词及 relaxed 纠正，保留原意。
2. `今天开会没说上话，有点失落，但同事后来主动问了我的想法。`：翻译不能夸大为被排斥；追问只问一个问题。
3. `I had a quiet day at home.`：不强行改写正确英语，解释为空。
4. `第一次离开家去大学，爸爸没有说话，只帮我提着箱子。`：回忆引导需追问细节或感受，不能替用户编造父亲心理。
5. 多轮之后归档：英文第一人称总结，只纳入用户事实，不把 AI 假设或问题写成事件。

每项以忠实度、英文正确性、单问题追问、中文辅助、JSON 合规率、延迟和实际 token 用量评估。每样本重复三次后才下结论。
