# 小日子云端快照同步设计

2026-11-23。用户已确认本文件的核心产品方案、自动同步时机、初始化、5 份备份规则和 CloudBase 上海作为首选，并进一步授权实现和配置已登录的腾讯云环境。决策见 [ADR-0002](adr/0002-passphrase-cloud-snapshot-sync.md)。正式域名、套餐和费用仍单独确认；实际部署验证结果见本文件后续记录。

## 已确认

- 仅供个人多设备使用，云端须在中国大陆直接可访问。
- 无邮箱登录。系统创建固定的长随机同步口令，不允许用户自定义或修改；创建时检查唯一性。
- 新设备可通过粘贴或扫码导入已有口令，连接同一同步空间。每台设备保存该凭据，后续自动上传、下载。
- 上传和下载整份日记快照，不逐篇合并。云端有新版本而本地有未上传修改时，先保留可恢复的本地备份，再以云端覆盖。
- 同步完整日记与未发送草稿；AI API 密钥、日记记忆设置和同步口令不包含在快照中。
- 每次打开尝试同步，显示状态图标。启动时先显示本地内容并短暂禁止编辑；约 3 秒后可继续离线编辑。
- 用户接受云端具有解密能力，不要求用户独立保管端到端加密密钥。

## 自动同步规则

打开应用、页面重新进入前台或网络恢复时检查云端。完成本地编辑后短暂等待约 2 秒，合并频繁保存并自动上传；浏览器休眠或退出时不承诺最后一次上传成功，本地保存仍立即执行。

云端自上次成功同步以来没有改变时，上传本地待同步内容；云端已有新版本时，按已确认规则先备份本地，再下载覆盖。没有本地修改时只接收云端更新。上传用预期云端版本进行校验；版本不匹配时重新拉取云端，防止两台设备先检查后上传的时间差使旧内容覆盖新内容。版本不能仅依赖设备时钟。

创建新同步空间时用当前本地日记初始化云端；连接已有空间时验证口令并下载，替换前保留本地备份。连接失败不能自动创建新空间。

本地覆盖前备份保留最近 5 份，提供查看、导出与明确恢复入口；备份失败时停止覆盖。恢复必须由用户明确发起；恢复后的内容属于本地修改，仍遵循上述上传版本检查与云端优先规则。

## 内容与请求保护

沿用现有存储安全要求：下载完整且校验通过、本地保存可成功后才替换当前集合；网络错误、错误口令、损坏文件、未知格式版本和存储空间不足不能清空原日记。

口令授权私有读写，不能仅把它当成公开文件名。云端须校验请求凭据，不能向浏览器暴露云服务管理密钥。具体口令验证、快照存储和请求协议随云服务选型确定。

应用应串行处理同步与本地替换，避免后台下载覆盖用户正在输入的新草稿或把旧日记的 AI 结果写进新版本。同步与下载不应自动发起付费 AI 请求。

## 状态图标建议

区分正在同步、已同步、本地修改待上传、离线、同步失败与云端覆盖后有可恢复备份。点击展示上次成功同步时间、错误说明、重试和备份入口。只有确认云端与本地对应同一版本、且没有待上传修改时才显示已同步。

- 首选腾讯云 CloudBase 上海环境，候选组合为 HTTP 云函数校验口令、私有快照文件和事务校验上传版本。具体 SDK、环境模式与接口仍需在实现时验证，不能照搬邮箱登录方案。官方能力与默认域名限制见 [调研记录](cloud-sync-research.md)。

默认域名仅用于验证，不作为正式运行方案。选择正式入口前需确认前端页面和云端 API 的完整大陆访问链路。

真实大陆手机网络访问、口令读写隔离、双设备并发与离线恢复需在最终方案实现后验证。
