# Little Days 国内云同步服务调研

调研日期：2026-11-23。只核对公开官方文档，未创建云资源、发送邮件或进行中国大陆真实浏览器连通性测试。

## 结论

用户最新方向已替代原邮箱登录方案：不提供账号/登录 UI，以首次生成、固定不变的随机共享密钥连接设备，云端保存权威 JSON 快照，本地只保存副本与待上传版本。下文邮箱能力表仅保留为历史调研，不再是当前实现建议。

CloudBase 上海环境仍是候选，尚未完成供应商选择或确定预算。官方能力支持“小型 HTTP 云函数自行验证共享密钥 + 完全私有快照文件 + 数据库事务提交版本指针”的试验方案。跨设备版本比较、失败重试和本地副本保护由应用实现；有云存储不代表已完成同步协议。建议先验证错误密钥拒绝、两台设备并发上传、请求丢失后的恢复及大陆手机网络访问，再确定正式套餐与域名。本文不承诺免费长期运行或全国网络稳定可达。

## 原邮箱方案：已核实的能力与条件（已被替代）

| 项目 | 官方事实 | 对本项目的影响 |
| --- | --- | --- |
| 邮箱验证码登录 | 身份认证 v2 明确支持“邮箱 + 邮箱验证码”；`getVerification({ email })` 发送验证码，再调用 `signInWithEmail({ verificationInfo, verificationCode, email })`。示例验证码为 6 位。[邮箱验证码登录](https://docs.cloudbase.net/authentication-v2/method/email-login) | 可只显示邮箱与验证码，不要求日记用户设置密码。应使用 v2 接口，避免照搬旧版邮箱密码登录示例。 |
| 邮件发送 | 控制台“身份认证 → 登录方式 → 邮箱验证码 → 配置发件邮箱”可开启内置邮件代发，无需 SMTP；也可配置自定义 SMTP。内置服务有每日发件限制，页面未给出确切数量。[邮箱验证码登录](https://docs.cloudbase.net/authentication-v2/method/email-login) | 个人试验可先用代发；上线前核实配额、实际送达率与收件邮箱兼容性。SMTP 授权码只能保存在云端配置。 |
| 新用户注册 | 官方支持邮箱验证码注册；流程包含发送、验证、注册；密码和用户名是可选项。注册成功自动登录。[用户注册](https://docs.cloudbase.net/authentication-v2/method/signup) | 要覆盖首次注册和已存在账号两条路径，不能仅测试老用户登录。文档后半段示例使用手机号变量，邮箱注册参数需结合当前 SDK API 核实。 |
| 国内地域 | 邮箱登录 SDK 示例明确使用 `region: 'ap-shanghai'`；静态网站托管概述标注支持地域“上海”。[邮箱登录](https://docs.cloudbase.net/authentication-v2/method/email-login)、[托管概述](https://docs.cloudbase.net/hosting/introduce) | 优先选择上海；不能从新加坡对国内站开放推导其服务器位于大陆，也不能推导所有登录和托管功能跨地域一致。 |
| 静态前端 | 静态托管支持 React、Vite、已构建产物、Node.js 24，提供 HTTPS 与 CDN。[托管概述](https://docs.cloudbase.net/hosting/introduce)、[纯静态项目部署](https://docs.cloudbase.net/hosting/web-hosting-static) | 可上传本项目 `dist/`，为前端提供国内服务候选入口。实际资源路径、缓存和手机网络仍需验证。 |
| 默认域名 | 提供默认域名，无额外配置即可访问，但定位为开发/测试，存在访问频率限制，超限会暂时不可访问；官方建议生产配置自定义域名。[控制台管理静态资源](https://docs.cloudbase.net/hosting/manage) | 默认域名适合验证，不宜作为“免费且无限访问”的正式方案。 |
| 自定义域名 | 自定义域名必须已完成 ICP 备案；需配置 SSL、域名归属校验和 DNS。边缘加速需要标准版以上，另产生流量和请求费用。[自定义域名](https://docs.cloudbase.net/service/custom-domain) | 正式前端入口需要提前确认域名、备案和预算。无需默认开启付费加速。 |
| CloudBase 备案资格 | 云环境可作为备案资源，但需个人版以上、剩余有效期至少 6 个月、开启云托管固定 IP；免费体验环境不支持。备案期间保持固定 IP；完成后可按需关闭。[ICP 备案](https://docs.cloudbase.net/icp/) | “只买免费环境即可国内自定义域名上线”不可行；也可使用其他符合资格的腾讯云资源，按账户实际情况选择。 |

## 同步与隐私边界

用户已接受后端能解密日记，故服务端可处理明文内容。当前方案应把每个快照归属到独立的密钥验证记录，由服务端校验共享密钥并拒绝其他记录的访问。原方案“绑定登录用户 ID”的要求随邮箱登录一起被替代。上述为本项目设计要求，不是本次已验证的部署成果。

候选实现方向：本地编辑保留副本，上传携带预期云版本和稳定操作 ID；版本不一致时不可静默覆盖云快照，也不可丢弃本地内容。全量 JSON 快照以云端当前版本为准；是否保存旧版本文件、保留多久属于独立的备份/运维选择。具体恢复与冲突规则见 [云快照同步设计](./cloud-snapshot-sync.md)。用户已确认 AI API key 不同步，日记记忆设置仍由每台设备单独配置。

## 无登录共享密钥方案：新增官方能力核实

| 项目 | 官方事实与证据 | 对候选架构的影响 |
| --- | --- | --- |
| 普通 HTTP API | HTTP 网关可将云函数关联到路径，支持默认/自定义域名；浏览器可用 `fetch`，无需 SDK。函数可接收方法、路径、请求头、JSON body，并返回 HTTP 状态码。[HTTP 访问云函数](https://docs.cloudbase.net/service/access-cloud-function) | 一个函数可承载 create/pull/push。此处指网关访问云函数，不要求搭建常驻容器。另有监听 9000 端口的 HTTP 云函数形态。[Node.js HTTP 云函数](https://docs.cloudbase.net/cloud-function/quickstart/httpfunc/nodejs) |
| 平台认证与自定义验证 | HTTP 网关身份认证由路由开关启用；启用后需要平台访问令牌，浏览器直接访问可跳转登录页。[身份认证](https://docs.cloudbase.net/service/authentication) | 当前方案应关闭该路由的平台身份认证，在函数内部验证应用生成的随机共享密钥；关闭平台认证不等于日记公开。管理员 API Key 只供服务端，绝不能下发浏览器。云托管若作为替代，其服务默认允许公开入口。[云托管公开访问](https://docs.cloudbase.net/run/deploy/authenticating/public) |
| 私有存储 | 传统模式云存储支持“仅管理员可读写”，前端不能直接访问，云函数可凭管理员权限访问。[存储基础权限](https://docs.cloudbase.net/storage/data-permission) | 快照设完全私有，浏览器只能通过验证密钥的函数取回 JSON；不可把文件 URL 当访问控制，不可改公共读。 |
| 私有元数据 | 文档数据库集合支持“无权限”，官方将其用于需要服务端处理的敏感数据。[数据库基础权限](https://docs.cloudbase.net/database/data-permission) | 存放密钥验证材料、当前版本、对象引用及操作 ID 的集合拒绝客户端直接访问；函数承担授权。 |
| 版本条件提交 | Node SDK 服务端事务保证 ACID，支持按 `doc` 读取与更新；采用快照隔离，修改锁定文档，写冲突会终止事务。事务上限 10 秒，官方要求避免事务内外部调用。[数据库事务](https://docs.cloudbase.net/database/transaction) | 可在同一事务读当前版本、检查 `expectedVersion`、提交新版本指针。两次并发写不可仅在事务外先读再覆盖。冲突错误格式和 SDK 重试行为仍需真实环境验证。 |
| 环境模式 | 云存储底层基于 COS；新环境默认 PG 模式，传统模式需创建环境时不开启 PostgreSQL。两种模式权限、上传链路不同。[云存储总览](https://docs.cloudbase.net/storage/introduce) | 本节私有预设权限与文档数据库事务组合是**传统模式候选**，不能直接套到 PG 模式。采用 PG 模式需另核实 RLS、服务端访问与 SQL 事务。 |
| 默认 API 域名与备案 | 网关概述说明生产浏览器直接访问必须使用自定义域名，但明确不包括 API/图片请求；默认域名仍仅适合开发测试，有限频及稳定性风险。[HTTP 网关概述](https://docs.cloudbase.net/service/introduce)；中间页文档进一步提醒默认域名可能因流量风控关停，严禁用于正式生产或大规模分发。[默认域名限制](https://docs.cloudbase.net/service/alias) | 可用默认域名做 API-only 验证，不能据此承诺正式上线无需备案。若绑定大陆自定义域名，官方明确要求 ICP 备案。[自定义域名](https://docs.cloudbase.net/service/custom-domain) |
| 跨域与限频 | HTTP 网关支持路由跨域设置、总请求及客户端频率限制；跨域错误需核对安全域名白名单和路由设置。[网关概述](https://docs.cloudbase.net/service/introduce)、[网关 FAQ](https://docs.cloudbase.net/service/faq) | 应配置前端来源与预检请求，限制公开 create 及验证失败流量；CORS 不能替代共享密钥验证。 |

推荐试验的最小存储流程为：先上传一个独立命名、完全私有的 JSON 快照对象，再以数据库事务验证预期版本并更新当前对象引用；对象上传不得放在事务内。事务成功后该指针才成为云端权威版本。若版本冲突或事务失败，旧指针保持有效，新对象是未引用对象，清理策略另行实现。这是基于上述能力提出的应用设计，不是官方提供的现成同步服务；本次未核实 COS 条件写，也不依赖其实现并发控制。

共享密钥应由安全随机数生成器产生足够熵，在设备本地保存；服务端保存验证摘要，验证通过后才能读取或提交快照。密钥属于持有即可访问的凭证，不是腾讯云管理员凭证，也不是端到端加密密码。用 HTTPS 请求头传递，避免 URL、日志和 Git 中记录密钥或日记内容。不可对“不可猜测”作绝对保证；手工恢复设备需要用户保存该密钥。本文没有核实该环境已启用何种静态存储加密，不能宣称默认启用 AES、端到端加密或云服务方不能读取。

## 尚未验证

- 当前账户可购买套餐、完整月费、资源点额度、免费体验期限、内置邮件每日数量和固定 IP 费用；应在实际控制台查看后决定预算。
- 无登录方案在实际环境的 HTTP 请求/响应大小、对象大小上限、套餐能力、Node 运行时、事务冲突错误与重试语义、重复上传幂等性和 API 域名政策；JSON 直接放单个数据库文档的大小可行性尚未验证，因此候选采用私有对象 + 小型元数据。
- 大陆电信/联通/移动、手机 Safari/Chrome 的实际访问表现。能从本机下载官方文档不代表用户的部署已通过大陆网络测试。邮箱送达和注册参数属于被替代方案的历史未验证项。
- GitHub Pages 现有前端入口的大陆可达性未验证。仅迁移后端不能解决前端入口无法打开的问题；正式方案需同时验证页面和 CloudBase 请求。
- 未比较其他供应商的完整功能或服务价格；目前证据已足够支持对 CloudBase 进行受控试验，不构成已完成的供应商选型或生产部署。
