# 当前日记同步上传限制

检查日期：2026-11-23。此记录来自应用源码和当前腾讯云 CloudBase 控制台只读检查，未进行大文件上传或压力测试，未调整配置。

## 应用限制

- `src/sync-format.ts`：整份日记快照的 UTF-8 JSON 上限为 4 MiB（4,194,304 字节），包含消息、草稿和日记元数据；不是单篇日记上限。未发现篇数或天数上限。
- `cloud/service.ts`：解码后的 POST 请求体最多为 4 MiB + 1024 字节，超出返回 413。私有存储中的 AES-GCM 文件增加 28 字节。
- `src/sync.ts`：客户端请求超时 20 秒；下载响应超过 5 MiB 会被拒绝。编辑停止 2 秒后尝试自动上传，这属于防抖，不是调用配额。
- 上传需符合来源校验、固定口令校验和云端版本校验。过期版本返回 409，避免直接覆盖其他设备的新版本。
- 云端成功上传的历史快照目前没有自动清理；会积累存储资源消耗。本地最多保留 5 份覆盖前备份，不代表云端仅保留 5 份文件。
