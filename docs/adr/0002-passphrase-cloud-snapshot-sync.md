# 使用固定口令自动上传与下载云端日记快照

2026-11-23，用户将邮箱登录与跨设备冲突版本选择方案改为无需账号登录的口令方案：在每台设备的设置中固定保存同步口令，此后上传与下载自动使用该口令。下载采用完整云端日记文件替换本地日记集合，不进行逐篇合并。如果本地存在尚未上传的修改而云端已有更新，用户确认先保留可恢复的本地备份，再以云端覆盖本地。

口令由系统首次生成足够长的随机值，不提供用户自定义或修改口令的入口。用户希望避免不同用户口令重复；实现应在创建同步空间时检查分配标识的唯一性，发生碰撞则重新生成，不能仅以随机概率代替唯一性检查。

用户确认新设备可以粘贴或扫描已有设备的口令，以连接同一个同步空间。这属于导入系统已有凭据，不是自定义或修改口令。设置提供“创建同步空间”和“连接已有空间”两条路径，连接成功后记住口令并自动上传、下载。

沿用已确认的个人使用、大陆直接可访问云端、同步完整日记与草稿、显示同步状态图标等要求。AI API 密钥和日记记忆设置仍按设备配置；同步口令属于本机设置，不包含在云端日记文件或日记导出备份中。用户此前接受云端具有解密能力，当前并未重新要求端到端加密。

## Consequences

无需账号登录界面不意味着云端文件公开读写：口令必须用于私有同步空间的访问授权，不能仅将它当作公开文件名。拥有同一口令的设备访问同一份云端日记快照。

用户确认打开应用、回到前台、网络恢复时检查云端，本地编辑停止约 2 秒后自动上传。云端未变化时上传本地修改；云端已有新版本时先备份本地再下载覆盖。创建空间时上传当前日记，连接已有空间时先备份再下载；本地保留最近 5 份覆盖前备份，提供查看、导出和恢复入口，备份失败时停止覆盖。

用户确认腾讯云 CloudBase 上海环境作为首选候选，先验证口令私有读写与双设备同步；正式域名、套餐与费用留到部署前另行确认，默认域名不作为正式运行方案。口令方案的官方能力调研见 [云服务调研](../cloud-sync-research.md)，完整产品规则见 [同步设计](../cloud-snapshot-sync.md)。

没有邮箱账号恢复机制；若口令和保存口令的设备全部丢失，无法通过邮箱找回云端数据。本地现有日记与备份仍可保留，不应因云端连接不可用被清空。

现有 JSON 导入保留已有日记，不能直接复用为下载覆盖。下载失败、内容损坏或本地持久化失败时应保留原本地数据；该内容安全原则沿用现有仓库要求。

本 ADR 仅记录当前已确认方向，不表示同步功能已经实现；当前应用行为仍见 [日记设计](../diary-design.md)。
